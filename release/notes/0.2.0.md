# ServerDeck 0.2.0

- Добавлена встроенная консоль сервера с интерактивным SSH-терминалом.
- В настройках приложения можно выбрать оболочку по умолчанию и сохранить собственные профили оболочек.
- MCP может работать в той же консоли: читать экран и историю текущей сессии, отправлять текст и управляющие клавиши.
- Добавлены передача управления вводом между пользователем и MCP, подтверждение многострочной вставки и защита от повторной отправки команд.
- Консоли сохраняются при переключении разделов и скрытии приложения в трей; история остаётся в памяти до закрытия сессии или выхода из приложения.
