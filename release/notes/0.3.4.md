# ServerDeck 0.3.4

ПО отображается готовой таблицей с колонками «Название», «Версия», «Служба»
и «Хост». Подробности одной выбранной записи и действия с ней доступны
в отдельной области. Таблица сохраняет встроенное адаптивное представление.

История хоста и карточки ПО стала компактным списком: тип события, название ПО,
превью сообщения, автор, время UTC и сообщённый исход. Полный исходный текст
и метаданные открываются через «Подробности события».

Превью ограничено 160 символами Unicode, включая многоточие; полный текст
сохраняется без сокращения. Поддерживаются управление с клавиатуры и прежние
ограничения действий для записей другого хоста.

Обновлено оформление общих кнопок в соответствии с дизайном компонентов.

Формат локальной базы, протокол MCP и зависимости не меняются.
