Текущая версия в основном окне

- Полный номер запущенной версии ServerDeck теперь виден в блоке состояния боковой панели.
- Номер остаётся доступным без выбранного сервера и при ошибке открытия данных.
- До получения локальных сведений показано «Не определена»; предлагаемое обновление не подменяет текущий номер.
- Настройки, пользовательские данные и правила подтверждения обновлений сохраняются.
