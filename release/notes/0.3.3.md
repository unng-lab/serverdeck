# ServerDeck 0.3.3

Карточки ПО стали компактнее: в сводке отображаются название, версия и исходный
хост. Служба, пути к данным и конфигам, время изменения и действия доступны
в раскрываемых «Подробностях».

Раскрытие карточек независимо и сохраняется при обновлении данных. При смене
профиля, страницы или фильтра карточки снова сворачиваются. Управление доступно
с клавиатуры.

Для карточек другого хоста предупреждение остаётся видимым в сводке;
ограничения изменения и открытия консоли сохраняются.

Формат локальной базы, протокол MCP и зависимости не меняются.
