# ServerDeck 0.3.1

Исправлено подключение MCP-клиентов, включая Codex: стандартное поле `_meta`
в запросе списка инструментов больше не вызывает `INVALID_PARAMS` при запуске.
Такие метаданные также поддерживаются при инициализации, ping и вызове инструментов.

Проверки разрешений и аргументов инструментов сохранены. Пересоздавать разрешение
клиента или менять его конфигурацию не требуется. Формат локальной базы не меняется.
