# ServerDeck 0.3.0

Вкладка ПО хранит локальные карточки установленных программ: название, версию,
службу и пути к данным и конфигам. Карточки доступны в интерфейсе и через MCP.
Изменения сохраняются в истории вместе с автором и временем; можно добавлять
краткие сообщения о выполненной работе.

ИИ использует существующую общую SSH-консоль для команд и работы с конфигами.
Раздел анализа сервера готовит задание для внешнего ИИ-клиента: обследовать сервер,
предложить карточки и сохранить согласованные сведения через обычный MCP CRUD.

Добавлены шесть методов `software.*`; существующие 21 MCP-метод сохранены.
Учёт ПО и история хранятся локально в ServerDeck. Установка отдельного агента
на сервер не требуется.

Сохранение и удаление карточки меняют только локальный учёт. Они не устанавливают
и не удаляют ПО на сервере. Формат локальной базы остаётся совместимым;
существующие профили, учётные данные и данные других функций сохраняются.
