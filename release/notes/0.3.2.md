# ServerDeck 0.3.2

Один MCP-клиент теперь может работать одновременно в нескольких чатах Codex:
ограничение двух подключений на разрешение удалено из native broker и Dart-адаптера.
Сохраняется общий предел восьми одновременных MCP-каналов на приложение.
Каждая сессия проходит авторизацию отдельно; закрытие одного чата не закрывает
остальные. Отзыв, замена и истечение разрешения затрагивают все его сессии.

Добавлено ограниченное автоматическое переподключение SSH с задержкой и jitter.

Пересоздавать разрешение MCP или менять конфигурацию клиента не требуется.
Формат локальной базы не меняется.
