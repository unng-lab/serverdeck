Обновления ServerDeck через GitHub Releases

- В установщик встроены источник релизов и публичный ключ проверки подписи.
- Проверка обновлений доступна при запуске, раз в 24 часа и вручную в настройках приложения.
- Скачивание начинается после подтверждения; установка выполняется при следующем запуске.
- Пользовательские данные, настройки и секреты сохраняются.
