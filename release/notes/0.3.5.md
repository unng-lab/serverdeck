# ServerDeck 0.3.5

После обрыва SSH ServerDeck продолжает попытки переподключения без ограничения
их количества. После восьмой попытки сохраняется задержка 15–30 секунд
со случайным разбросом. Ручная отмена и отключение останавливают повторы;
ошибки доверия, авторизации и запрос passphrase требуют действия пользователя.
В интерфейсе показывается номер текущей попытки без общего лимита.

Из таблицы ПО можно перейти к журналам соответствующей службы.
Для служб с редкими событиями сохраняются последние 200 записей журнала.

Формат локальной базы и зависимости не меняются. Диапазон номера попытки
в ответах MCP расширен; остальные поля и правила доступа сохранены.
