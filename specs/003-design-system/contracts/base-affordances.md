# Действия и защитные ограничения базовых 37 экранов

Версия: 2026-10-28. Это читаемая справка о существующих действиях и guards. [FA07/FA07.1](full-application.md) определяют честные результаты и композицию93. Справка не является исполняемым manifest или отдельной схемой тестового протокола.

Обычные callbacks, доступность действия и фактический target проверяются непосредственно в production widgets и meaningful unit/widget tests. Общий текст кнопки не разрешает generic handler, скрытый запрос или смену цели.

Реальные данные выбираются по actual profile/record identity и current generation. Канонические имена, адреса, версии и идентификаторы не попадают в контекст исполнения. Переходы не подключают сервер и не принимают доверие; локальные query/sort/filter работают только над уже загруженными списками. Отсутствующее поле DTO отключает точный фильтр с объяснением, а не создаёт фиктивное значение или новый API. Counts относятся только к загруженному scope. Next использует существующий cursor только там, где owner его даёт; другие переходы используют уже загруженные окна либо остаются на границе с причиной.
