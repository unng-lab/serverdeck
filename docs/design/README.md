# Дизайн ServerDeck

Версия эталона: 2026-10-25. Основа — [брендбук 1.1](../brandbook/README.md) с неизменными [токенами палитры и типографики](../brandbook/tokens/serverdeck.tokens.json).

[Открыть автономный атлас](ServerDeck-design.html) · [Визуальные правила](DESIGN.md) · [Реестр 98 экранов](screens.json) · [Пакет Spec Kit 003](../../specs/003-design-system/spec.md)

HTML открывается в браузере без установки программ и без сети. Каталог, поиск, две темы и четыре контрольных размера встроены в файл. Композиции используют демонстрационные данные и действия. Файл не подключается к инфраструктуре и не является альтернативным рабочим клиентом.

`screens.json` сохраняет стабильные ID, группы, виды композиций и источники. Пути источников относительны корню репозитория. `implemented: true` у 35 записей означает наличие связанного сценария в коде на момент инвентаризации, а не соответствие всем действиям макета или прохождение приёмки. Остальные 63 записи — концепты профильных пакетов. Дизайн, наличие поведения и приёмка имеют разные статусы.

Приоритет источников: требования продукта и полномочий соответствующего пакета → брендбук и точные токены → композиция атласа. Пример в макете не меняет Local API, разрешения, доверие, контроль записи, правила хранения или фактические возможности клиента. Применение к Flutter описано в [плане 003](../../specs/003-design-system/plan.md).

В этой папке хранится стабильная копия согласованного локального атласа из `output/design-all-pages-2026-10-25`. PNG и контактные листы из исходного экспорта являются вспомогательными материалами; просмотр всех композиций доступен в HTML. Шрифты Noto Sans/Noto Sans Mono встроены; [лицензия OFL](OFL.txt) приложена. Логотипы и исходные шрифты также находятся в `assets/brand/` репозитория.

Проверки HTML не заменяют Flutter widget tests, проверки реальных контроллеров или техническую приёмку будущих модулей. Результаты каждого этапа фиксируются отдельно в пакете 003.
