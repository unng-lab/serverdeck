Редактирование

Макеты SVG имеют редактируемые векторные фигуры и текст, размер 1440 × 900. Откройте их в Figma, Illustrator или Inkscape; для живого текста установите приложенные Noto Sans Regular/SemiBold и Noto Sans Mono Regular. Это векторные макеты, не файл с Figma-компонентами и auto-layout. Исходный генератор в source/build.py позволяет пересобрать PDF и SVG одновременно.

Логотипы

logos содержит цветные и монохромные варианты logo, mark и app-icon. Суффикс dark означает размещение на тёмном фоне, light — на светлом. SVG логотипов сохранён контурами и не требует шрифта; PNG также готов к использованию. PNG логотипов и знаков имеет прозрачный внешний фон, иконки приложения — сплошной квадрат для маски ОС. Для редактирования живого текста в макетах установите приложенные шрифты. Охранное поле указано в PDF; экспорт может требовать дополнительных внешних отступов при размещении.

Flutter

HEX #RRGGBB → Color(0xFFRRGGBB), размеры → logical px. Сохранить токены bg/surface/text/accent, не генерировать остальные цвета автоматически через fromSeed. Семантические цвета, chart2/chart3, control и selected вынести в ThemeExtension; onError = bg. Токены предназначены для новой реализации клиента. Подключить fonts через pubspec.yaml с лицензией OFL, а также веса 400/600. Плотность строк 36/44 px, текст таблицы 13/20 px. Выделение и фокус могут присутствовать одновременно; focus рисуется поверх выбранного состояния. onAccent допустим только на accent и accentHover.

Контраст

Отчёт содержит исходные HEX, коэффициенты без округления при оценке, пороги и роль каждой пары. Метод WCAG: преобразование sRGB в линейный RGB, L=0.2126R+0.7152G+0.0722B, отношение (Lmax+0.05)/(Lmin+0.05). Текст ≥4.5:1; существенные границы/фокус/линии ≥3:1. Декоративный border исключён. Цветные подписи и графики разрешены на bg, surface, raised, hover и selected. disabled проверен дополнительно. Для кнопок проверен onAccent на normal/hover. Полная доступность приложения проверяется после внедрения.

Источники и лицензии

WCAG 2.2: 1.4.3 Contrast Minimum · 1.4.11 Non-text Contrast · Noto fonts / OFL · Приложенная лицензия. Знак разработан для этого брифа; поиск товарных знаков не проводился. Данные серверов, версии и журналы в макетах демонстрационные, не результат проверки инфраструктуры.
