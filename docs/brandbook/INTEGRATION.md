# Применение брендбука

Сохранён исходный брендбук, токены, artwork, шрифты, лицензии и генераторы. История прежней интеграции находится во внешнем архиве из [RESET](../../RESET.md).

Runtime assets: `assets/brand/`; Flutter-тема: `lib/theme/brand_theme.dart`, точные роли из `tokens/serverdeck.tokens.json`. Используются Noto Sans 400/600, Noto Sans Mono 400 и Noto Sans SC с сохранёнными лицензиями. Палитра не генерируется из seed.

Брендбук описывает визуальную идентичность, а не страницы нового приложения. Проверки токенов, контраста и assets: `test_design/components/foundations_test.dart`. Команды запуска: [quickstart 001](../../specs/001-design-system/quickstart.md).
