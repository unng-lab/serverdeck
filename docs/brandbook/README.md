# ServerDeck: брендбук 1.1

10.10.2026 пользователь выбрал вариант №1 «Модули»: три горизонтальных серверных модуля, каждый с индикатором и слотом. Версия 1.1 заменяет только логотип и его применения; палитры, шрифты, токены и структура экранов сохранены.

## Размещение и использование

Редактируемый источник и полный комплект хранятся здесь, в репозитории: `source/build.py`, `source/package.py`, `layouts/`, `logos/`, `fonts/`, `tokens/`. Отдельный репозиторий или submodule не нужен. Готовые к использованию копии находятся в `../../assets/brand/logos/`. В текущем checkout клиент ещё не реализован; подключение ассетов выполняется при реализации клиента.

- `logo-*`: знак с названием; `mark-*`: самостоятельный знак, прозрачный фон.
- `dark` размещается на тёмном фоне, `light` на светлом; `mono-dark` и `mono-white` — монохромные версии.
- SVG логотипов содержит контуры и не зависит от установленных шрифтов. PNG сохраняет прозрачные вырезы.
- `app-icon-*`: квадрат с фоном, 1024 px. Цветные растровые размеры: 256, 128, 64, 32, 24, 16 px; ICO содержит 16, 24, 32, 48, 64, 128, 256 px.
- Геометрия: сетка 64×64, три модуля 40×12 при x=12, y=9/26/43, радиус 3. Индикаторы 4×4, слоты 17×4, радиус 1. По сравнению с эскизом выбранного варианта знак сдвинут вниз на 3 единицы для центрирования в квадрате.
- Масштаб знака и охранное поле в PDF относятся к его квадратной сетке; реальный силуэт занимает 40×46 единиц. Минимум самостоятельного знака — 24 px, полного логотипа — 140 px по ширине. Размер 16 px предназначен только для системной иконки: внутренние детали там сглаживаются.

## Пересборка

Установите зависимости из `source/requirements.txt`; нужен Poppler (`pdftoppm`). В `source/build.py` путь Poppler настроен для локального Codex runtime, на другой машине измените его на путь установленного инструмента.

```powershell
python source/build.py
python source/package.py
Copy-Item logos/* ../../assets/brand/logos/ -Force
```

Архив выпуска: `../../output/ServerDeck-brandbook-kit-v1.1.zip`; исходный архив версии 1.0 сохранён. Результаты автоматической проверки: `verification.json`. Визуально проверяются страницы PDF и маленькие иконки; автоматические проверки не заменяют эту проверку.
