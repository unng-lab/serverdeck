# ServerDeck 0.2.0-preview.1+2 — source preview

Public release assets contain source code and checksums only. The Windows x64
review bundle is built and installed locally; it is not a public binary asset.

This preview brings the responsive ServerDeck design to the existing Windows
client: shared brand components, light/dark themes, compact layouts, accessible
forms and bounded dialogs, and explicit server context for retained results.

The reference atlas contains 98 screens. The 35 existing UI origins are
implemented; the other 63 remain concepts and are not advertised as runtime
features. The completed design scope and verification are recorded in the
[design handoff](../../specs/003-design-system/handoff.md).

## Installation and data

Requires Windows 11 x64 and the Microsoft Visual C++ 2015–2022 x64 runtime.
The full Release bundle contains the client, locald, MCP bridge, Isar library,
executor descriptor, Flutter runtime, fonts and assets. Keep these together.
The build uses the repository's pinned Flutter 3.47.7 / Dart 3.13.5 and lockfiles.

Close ServerDeck and connected MCP clients normally before switching versions.
The current-user installation uses a new versioned directory under
`%LOCALAPPDATA%\Programs\ServerDeckNext`. Update the Start menu shortcut only
after copying and verifying the complete bundle and setting its manifest's
`appRoot` to that installation directory. The old application directory remains.

This update retains the current format-3 workspace at
`%LOCALAPPDATA%\ServerDeckNext\v1\workspaces\default`, including its own profiles,
settings and protected credentials. It does not import an older product's data,
reset the workspace, install a remote executor or run server actions.

## Preview boundaries

This is a review build, not a signed production installer. Windows installer,
updater, public production distribution, full foundation/MCP acceptance and
other-platform acceptance remain outside this release's completed scope.
The existing native library provider is the historical development-cache
provider; a newly qualified distributable native artifact is not claimed.
SHA-256 checks identify artifacts and do not replace publisher signatures.
